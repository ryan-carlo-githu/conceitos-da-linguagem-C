📚 Estudos da Linguagem C

Este repositório foi criado com o objetivo de registrar e organizar minha jornada de estudos na linguagem C.

Aqui serão armazenados códigos, exercícios, exemplos e pequenos projetos desenvolvidos durante o aprendizado da linguagem.

A ideia é utilizar este repositório como um ambiente de prática e consulta, permitindo acompanhar minha evolução ao longo do tempo.

🎯 Objetivo

O principal objetivo deste repositório é praticar os fundamentos da linguagem C por meio da implementação de pequenos programas e exercícios.

Durante os estudos, pretendo explorar conceitos como:

Variáveis e tipos de dados
Entrada e saída de dados
printf e scanf
Operadores e cálculos
Estruturas condicionais
Estruturas de repetição
Funções
Arrays e strings
Ponteiros
Structs
Manipulação de arquivos
Alocação dinâmica de memória
Exercícios práticos
Pequenos projetos

Este repositório será atualizado conforme novos conceitos forem estudados e praticados.

🌱 Processo de aprendizado

A proposta deste repositório não é apresentar códigos perfeitos ou soluções profissionais.

O foco principal é aprender, praticar e documentar a evolução.

Por isso, alguns códigos podem apresentar diferentes abordagens ou soluções mais simples, pois fazem parte do processo de aprendizado da linguagem.

Com o avanço dos estudos, os códigos poderão ser revisados e aprimorados.
