# 📚 Estudos da Linguagem C

Repositório criado para registrar e organizar minha jornada de estudos na linguagem C.

Aqui serão armazenados códigos, exercícios, exemplos e pequenos projetos desenvolvidos durante o aprendizado da linguagem.

O objetivo é utilizar este repositório como um ambiente de prática e consulta, permitindo acompanhar minha evolução ao longo do tempo.

---

## 🎯 Objetivo

O principal objetivo deste repositório é estudar e praticar os fundamentos da linguagem C através de exercícios e pequenos programas.

Durante os estudos, serão abordados conceitos como:

- Variáveis e tipos de dados
- Entrada e saída de dados
- `printf` e `scanf`
- Operadores e cálculos
- Estruturas condicionais
- Estruturas de repetição
- Funções
- Arrays
- Strings
- Ponteiros
- Structs
- Alocação dinâmica de memória
- Manipulação de arquivos
- Exercícios práticos
- Pequenos projetos

Este repositório será atualizado conforme novos conceitos forem estudados e praticados.

## 🌱 Processo de Aprendizado
Este repositório não tem como objetivo apresentar códigos perfeitos ou soluções profissionais.

O principal objetivo é:

Aprender → Praticar → Testar → Corrigir → Evoluir

Por esse motivo, alguns códigos podem apresentar soluções simples ou diferentes abordagens para um mesmo problema.

Isso faz parte do processo de aprendizado e evolução na linguagem C.

Conforme os conhecimentos forem aprimorados, os códigos poderão ser revisados e melhorados.
